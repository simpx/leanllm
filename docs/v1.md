新增内容
--------

1. Qwen 模型结构实现
2. Qwen 权重加载映射
3. 支持 Qwen 特有的配置参数

Qwen vs GPT-2 差异
------------------
| 特性 | GPT-2 | Qwen3 |
|------|-------|---------|
| 位置编码 | Learned positional embedding | RoPE (Rotary Position Embedding) |
| 激活函数 | GELU (tanh) | SiLU |
| Layer Norm | 标准 | RMSNorm |
| QKV bias | 有 | 无 |
| 架构名称 | GPT2LMHeadModel | Qwen2ForCausalLM |

实现计划

### 1. 新增 RMSNorm (leanllm/models/base.py)
```python
class RMSNorm(nn.Module):
    """Root Mean Square Layer Normalization"""
    def __init__(self, hidden_size: int, eps: float = 1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(hidden_size))
        self.eps = eps
    
    def forward(self, x):
        variance = x.pow(2).mean(-1, keepdim=True)
        x = x * torch.rsqrt(variance + self.eps)
        return self.weight * x
```

### 3. 更新 engine.py
```python
def __init__(self, model_id: str, ...):
    if "gpt2" in model_id.lower():
        self.model = self._load_gpt2(hf_cfg)
    elif "qwen" in model_id.lower():
        self.model = self._load_qwen(hf_cfg)
    else:
        raise ValueError(f"Model {model_id} not supported")

def _load_qwen(self, hf_cfg):
    model = Qwen3(
        vocab_size=hf_cfg.vocab_size,
        hidden_size=hf_cfg.hidden_size,
        num_layers=hf_cfg.num_hidden_layers,
        num_heads=hf_cfg.num_attention_heads,
        max_position_embeddings=hf_cfg.max_position_embeddings,
        rope_theta=hf_cfg.rope_theta,
    )
    hf_model = AutoModelForCausalLM.from_pretrained(self.model_id)
    load_qwen_from_hf(model, hf_model.state_dict())
    del hf_model
    return model.to(device=self.device, dtype=self.dtype)
```

挑战与注意事项
-------------
1. **SwiGLU 激活**：Qwen3 的 MLP 使用 SwiGLU，需要 gate_proj 和 up_proj 两个投影
2. **RMSNorm**：替代标准 LayerNorm，实现更简单但需要正确处理 eps
3. **RoPE 参数**：需要从 config 读取 `rope_theta`（Qwen3 默认值待确认）
4. **中文 tokenizer**：Qwen3 主要针对中英文优化，需要测试中文输出
5. **权重形状**：Qwen3 权重已经是 PyTorch Linear 格式 (out, in)，无需像 GPT-2 那样转置
